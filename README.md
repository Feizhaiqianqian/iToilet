## 项目简介

iToilet 是智能卫浴领域的**重新发明者**。

我们注意到，人类已经能把火箭送上火星、把芯片刻到 3 纳米，却依然在用一根绳子解决人类最古老的生理需求。这是一个**文明级别的尴尬**。

于是我们决定：**把马桶重做一遍。**

不是改良，不是迭代，是**重新定义人与马桶的关系**。

### 第二代 · 分化

| 型号 | 简介 |
|---|---|
| **iToilet Hi-Fi 版** | 为音乐发烧友打造。支持 192kHz/24bit 无损音质，让每一次冲水都是听觉盛宴。 |
| **iToilet 蓝牙版** | 便捷连接，智能配对。靠近自动开盖，离开自动冲水，再也不用动手。 |
| **iToilet 家庭版** | 实现"系列"互联的起点。爸爸的马桶、妈妈的马桶、孩子的马桶，全家桶互联互通。 |
| **iToilet 探索版** | 全透明结构设计，满足您从三岁起就有的"十万个为什么"。看得见的冲水，才是放心的冲水。 |

### 第三代 · 极致

| 型号 | 简介 |
|---|---|
| **iToilet Air** | 极致轻薄，开盖即屎。重新定义"轻装上阵"。 |

## 核心功能

- **🎵 高保真音响** — Hi-Fi 版专属，让如厕变成一场沉浸式音乐会
- **📡 智能互联** — 蓝牙与家庭版支持多设备协同，马桶也能组网
- **👁️ 透明探索** — 探索版全程可视，机械美学一览无余
- **🪶 轻薄设计** — Air 版把重量做到极致，重新思考"轻"的意义
